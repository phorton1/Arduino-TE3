High Level Design

The software and detailed technical design documentation is split among several separate repositories. This repository contains the TE3.ino program that is the main USB Midi Device and central-coordinator running on a teeensy4.1, along with the most recent technical documents, including:

  • An overview of the full system architecture and design
  • A history of various TE3 prototypes I created along the way
  • Details about the electronics circuits used in the box
  • A more detailed look at the design of the software
  • The initial implementation effort, and
  • Implementation details discovered along the way

In addition to this repository, the other two main programs are the TE3_audio.ino program and the Looper program. They both have their own technical documentation, particularly the Looper:

  • TE3_audio repository contains the TE3_audio.ino program which is the USB Audio Device running on a teensy4.0 with a teensy Audio shield, along with its associated technical documentation.
  • The circle-Looper repository contains the source code for the Looper program that runs in bare metal on a Raspberry Pi Zero2W, along with its associated technical documentation.
