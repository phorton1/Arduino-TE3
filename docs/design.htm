High Level Design

The software and detailed technical design documentation is split among several separate repositories. This repository contains the TE3.ino program that is the main USB Midi Device and central-coordinator running on a teeensy4.1, along with the most recent technical documents, including:

  • An overview of the full system architecture and design
  • A history of the specific TE3 prototypes I started with
  • Details about the electronics circuits used in the box
  • A more detailed overview of the design of the software
  • The initial implementation path for the project
  • Implementation details

In addition to this repository, the other two main programs are the TE3_audio.ino program and the Loopper program.

  • TE3_audio contains the TE3_audio.ino program which is the USB Audio Device running on a teensy4.0 with a teensy Audio shield, and its associated technical documentation.
  • The circle-Looper repo contains the source code for the Looper program that runs in bare metal on a Raspberry Pi Zero2W, along with its own associated technical and historical documentation.
